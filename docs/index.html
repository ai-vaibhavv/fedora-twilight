a quiet dusk for your desktop

Fedora Twilight

A soft purple, blue and pink GNOME setup, from the top bar to the login screen. You install it with one command and can recolour it from your own wallpaper. Updates and reboots don't break it.

git clone https://github.com/ai-vaibhavv/fedora-twilight && cd fedora-twilight && ./install.sh

The look

Every colour was picked from a single dusk illustration: the indigo sky, the lavender clouds and the pink horizon.

The palette

These colours all live in one file, palette.conf. Change them and re-run the installer to recolour every piece at once.

What's inside

Most of it is well-known open-source projects, pinned to tested versions and tuned to work together.

Colloid + Catppuccin

GTK and Shell theme, with a transparent top bar made of floating pills.

Pastel window buttons

Close, minimise and maximise dots. The symbols appear on hover, and the buttons look the same in GTK 3, GTK 4 and Qt.

Qt & LibreOffice title bars

A patched QAdwaitaColorfulDecorations, so Qt apps stop looking out of place.

Lock & login screen

WACK Sonoma lock screen with an Inter clock and Sacramento date, also shown on GDM.

Icons, cursor, fonts

Papirus Dark with violet folders, Catppuccin Mocha Lavender cursor, Inter, and JetBrains Mono.

Extensions

Dash to Dock, Just Perfection, Tiling Shell, Rounded Windows, Burn My Windows, Clipboard Indicator, Caffeine, Weather O'Clock.

Make it yours

Tested on Fedora Workstation 44 (GNOME 50). Takes about five minutes, most of it downloads.

  1. Get the repo

    You need nothing but a fresh Fedora Workstation.

    git clone https://github.com/ai-vaibhavv/fedora-twilight
cd fedora-twilight

  2. Pull colours from your wallpaper (optional)

    Skip this to keep the original Twilight colours.

    # preview the suggested palette in your terminal
./scripts/palette-from-wallpaper.py ~/Pictures/wall.jpg
# happy? save it to palette.conf (you can still hand-edit it)
./scripts/palette-from-wallpaper.py ~/Pictures/wall.jpg --write

  3. Install

    It asks for your password when it installs packages and the login-screen extension.

    ./install.sh --wallpaper ~/Pictures/wall.jpg

  4. Log out and back in

    That loads the Shell theme, the extensions, and the Qt settings. Done.

Re-running only some parts 
./install.sh --list            # packages theme gtk icons cursor fonts sounds extensions qt lockscreen settings heal
./install.sh --only gtk,qt     # e.g. after editing the button colours
./install.sh --no-sudo         # everything that doesn't need root

Built to survive updates

Most desktop customisations quietly vanish after a dnf upgrade. This one was designed so it doesn't.

Pinned upstreams

Colloid, the Qt plugin, WACK and Rounded Windows are fetched at exact commits, so a reinstall next year looks the same.

Layered, never patched

Tweaks sit on top of the themes, in ~/.config/gtk-3.0 and marked blocks, instead of editing files that updates overwrite.

Self-repair at login

twilight-heal.service rebuilds the Qt plugin after Qt updates and restores anything that was undone. It notifies you when something needs root.

Hands off /usr

Nothing that dnf owns is modified, so updates and Twilight never fight over a file.
